## 스토어 등록정보 (Store listing)

- **이름**: 쇼크트리AI
- **요약 (132자 이내)**:
  쇼크트리에서 버튼 한 번으로 쿠팡 윙의 경쟁 상품 판매 데이터와 광고센터 광고비 보고서를 가져옵니다.
- **카테고리**: 생산성 (Productivity) 또는 비즈니스 도구
- **언어**: 한국어
- **설명**:

```
쇼크트리(hoonproai.com) 회원을 위한 쿠팡 판매 도우미입니다.

■ 소싱AI — 경쟁 상품 판매 데이터
소싱AI 상품 목록에서 [윙에서 바로 가져오기]를 누르면, 같은 크롬에 로그인된 쿠팡 윙의 상품 검색으로
경쟁 상품의 최근 28일 조회수·판매량을 읽어 구매전환율·월 매출과 함께 보여줍니다.

■ 정산AI·광고분석AI — 광고비 가져오기
[광고센터에서 바로 가져오기]를 누르면 쿠팡 광고센터에서 내 광고 보고서를 만들어 받아,
순이익 계산과 광고 분석에 바로 반영합니다. 보고서를 내려받아 올리는 과정이 필요 없습니다.

■ 이렇게 동작합니다
- 쇼크트리 화면에서 버튼을 눌렀을 때만 동작합니다.
- 쿠팡 아이디·비밀번호·로그인 정보는 읽거나 저장하지 않습니다. 쿠팡 요청은 브라우저의 기존 로그인으로 보냅니다.
- 쿠팡 윙(wing.coupang.com)·광고센터(advertising.coupang.com) 로그인이 필요합니다.

쇼크트리 회원 전용입니다. 이용 방법: hoonproai.com
```

## 개인정보 보호 (Privacy practices)

- **단일 목적 (Single purpose)**:
  쇼크트리 회원이 쿠팡 윙과 광고센터에서 본인 판매·광고 데이터를 쇼크트리로 가져오도록 돕는다.
- **권한 사유**:
  - `host_permissions: wing.coupang.com` — 이용자가 고른 경쟁 상품의 최근 28일 조회수·판매량을 쿠팡 윙 상품 검색으로 조회
  - `host_permissions: advertising.coupang.com` — 이용자 본인의 광고 보고서를 만들고 내려받기
  - `cookies` — 쿠팡 윙 요청에 필요한 XSRF 토큰 확인, 팝업에 로그인 여부 표시 (값을 저장·전송하지 않음)
  - `scripting` — 직접 요청이 거절될 때 이용자의 윙·광고센터 탭 안에서 같은 조회 실행
  - `tabs` — 열려 있는 윙·광고센터 탭을 찾고, 없으면 잠깐 열었다 닫기
  - content script (hoonproai.com) — 쇼크트리 화면의 버튼과 확장 프로그램 연결
- **원격 코드 사용**: 아니요 (모든 코드가 패키지 안에 있음)
- **수집하는 데이터** (체크): 웹사이트 콘텐츠 — 쿠팡 상품 통계와 이용자 본인의 광고 보고서.
  개인 식별 정보·인증 정보·위치·웹 기록은 수집하지 않음.
- **인증**: 판매하지 않음 / 핵심 기능과 무관한 용도로 쓰지 않음 / 신용 평가에 쓰지 않음 — 세 가지 모두 체크
- **개인정보처리방침 URL**: https://hoonproai.com/extension-privacy.html

## 심사 전 알아둘 것

- 쿠팡의 공식 API가 아니라 쿠팡 화면이 쓰는 내부 요청을 이용한다. 웹스토어 심사와는 별개로 쿠팡 약관상
  제한될 수 있다.
- 심사관이 쿠팡 계정 없이 시험할 수 없으므로, 심사 메모(Test instructions)에 "쇼크트리 회원·쿠팡 판매자
  계정이 있어야 동작하며, 버튼을 누를 때만 쿠팡에 요청한다"고 적는다.
- 공개 범위를 처음에는 "비공개(링크가 있는 사용자만)"로 하면 심사 후 링크로만 설치하게 할 수 있다.
