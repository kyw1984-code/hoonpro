> 2026.08 확정 — 월 구독 · 카드 자동결제 모델 전환 실행 계획.
> 결제 = 토스페이먼츠 빌링, 본인인증 = 포트원(PASS), DB = Supabase(기존 유지).

## 0. 확정된 결정사항

| 항목 | 결정 |
|------|------|
| 월 구독 가격 | **39,800원 / 월** (단일 플랜으로 시작, 티어 분리는 데이터 축적 후) |
| 기존 수강생 정책 | **전원 무료 쿠폰 1개월** — 오픈 시점 일괄 발급, CI 기준 1인 1회 |
| 환불 기준 | **7일 이내 미사용 → 전액 환불** (전자상거래법 청약철회) + **그 외 → 잔여 기간 일할 환불** |
| PG 준비 상태 | 통신판매업 신고 **완료** · 토스페이먼츠 **가입·사용 중** → 남은 것은 ①토스 **자동결제(빌링) 추가 심사** ②포트원 본인인증 심사 |

- 일할 환불 계산: 월 39,800원 ÷ 30일 ≈ **1,327원/일** × 잔여일수 (원단위 절사). 약관에 산식 명시.
- ⚠️ 토스페이먼츠 일반결제 가입과 **빌링키 자동결제는 별도 계약**입니다. 기존 상점(MID)에 빌링 서비스를 추가 신청해야 하며 심사 3~7영업일 — 이것이 남은 유일한 결제 측 병목이므로 즉시 접수.

## 1. 기술 스택

| 영역 | 선택 | 이유 |
|------|------|------|
| 정기결제 | 토스페이먼츠 빌링 | 카드 등록 시 빌링키 발급 → 서버가 매월 자동 결제. 이미 토스 가입되어 있어 빌링 추가 심사만 필요. 수수료 일반 ~3.3%(영세·중소 우대 시 인하) |

| 결제 알림 | 이메일 발송 (Resend 등) | 결제 예정·성공·실패 고지. **결제일 최소 7일 전 사전 고지는 법적 의무**(여신전문금융업법) |

## 3. 사용자 플로우

### 가입 — 본인인증으로 1인 1계정

현재 가입은 이름·연락처·이메일 입력 후 **관리자 수동 승인**(`users.status = pending/approved`) 구조입니다. 유료화 후에는 수동 승인을 **본인인증 + 구독 게이트로 대체**합니다 (관리자 차단 기능은 유지).

1. 이름 · 이메일 입력 (기존 화면 유지, 인증 단계 추가)
2. 휴대폰 본인인증 (PASS) — 인증 결과를 **서버에서 검증**해 CI값 추출, 만 14세 미만 차단
   - 신규 CI → 가입 완료, 계정에 CI 저장 (연락처는 인증 결과의 번호로 자동 입력)
   - 기존 CI → "이미 가입된 계정이 있습니다" 안내 — 무료 쿠폰 재가입 어뷰징 원천 차단

### 구독 시작

1. 플랜 확인(39,800원/월) → 쿠폰 코드 입력(선택, 입력 즉시 서버 검증)
2. 카드 등록 — 토스 결제위젯. 카드번호는 토스가 보관, 서버는 **빌링키만 암호화 저장**
3. 첫 결제
   - 무료 1개월 쿠폰 → 0원 결제, 1개월 후 첫 자동결제 (카드는 미리 등록)
   - 할인 쿠폰 → 할인가 즉시 결제
   - 쿠폰 없음 → 39,800원 즉시 결제
4. 구독 활성화 → 전 기능 사용 가능, 영수증 이메일 발송

### 매월 자동결제 (매일 새벽 크론)

1. 오늘이 결제일인 구독 조회 → 빌링키 결제 시도
   - 성공 → 다음 결제일 +1개월, 영수증 이메일
   - 실패 → D+1, D+3 재시도(총 3회), 카드 변경 안내 이메일
2. 3회 실패 → 구독 '정지'(past_due→paused). 기능 잠금, 데이터(관심 키워드·순위 추적 이력 등)는 보존 → 카드 재등록 시 즉시 복구

### 해지 · 환불

- 해지: 마이페이지에서 즉시 신청 → 남은 기간까지 이용 후 종료(자동결제만 중단). 재구독 자유, 이탈 고객 재구독 쿠폰 발급 가능
- 환불: **결제 후 7일 이내 + 사용 이력 없음 → 전액 환불** / 그 외 요청 시 **잔여 기간 일할 환불**(1,327원/일 × 잔여일, 즉시 이용 종료). 사용 이력 판정 기준은 `api_calls`·`api_usage` 레코드 존재 여부로 명확히

## 4. 쿠폰 시스템

| 속성 | 설계 |
|------|------|
| 유형 | ① 무료 기간(예: 1개월) ② 정률 할인(예: 30%) ③ 정액 할인(예: 10,000원) |
| 적용 범위 | 첫 결제 1회만 / 첫 N개월 / 계속 — 쿠폰마다 설정 |
| 발급 방식 | 코드형(예: `HOONPRO1M` — 수강생 단체 배포) + 개별 발급형(1인 1코드) |
| 제한 | 유효기간 · 총 사용 횟수 · **1인(CI 기준) 1회** — 재가입 어뷰징 불가 |
| 관리 | 관리자 패널에 쿠폰 생성 / 발급 현황 / 사용 통계 섹션 추가 |

**확정 활용**: 오픈 시점 기존 수강생 전원에게 **무료 1개월 쿠폰** 발급(체험 후 전환 유도) · 이벤트 할인 · 이탈 고객 재구독 쿠폰.

## 5. DB 스키마 (Supabase — 기존 `supabase-schema.sql`에 추가)

```
plans              플랜 (이름, 월 가격 39800, 상태)
subscriptions      user_id · plan_id · 상태(trial/active/past_due/paused/canceled)
                   billing_key(암호화) · current_period_end · next_billing_at · canceled_at
payments           결제 이력 (주문번호, 금액, 상태, 토스 paymentKey, 실패사유, 영수증URL)
coupons            코드 · 유형 · 값 · 적용범위 · 유효기간 · 총한도 · 상태
coupon_redemptions coupon_id · user_id · ci(unique) · 적용 구독 · 사용일
users 확장         ci(unique) · phone_verified_at · birth(만 14세 체크)
                   ※ status(pending/approved/rejected)는 유지하되 신규 가입은 인증 통과 시 자동 approved
```

## 6. 시스템 구성과 접근 제어

- **`/api/billing.ts` 신규 1개** (action 통합 — 함수 수 절약): `subscribe`(빌링키 발급·첫 결제) · `cancel` · `resume` · `change-card` · `coupon-validate` · `refund` · `webhook`(토스 결제 상태 수신, 서명 검증) · `charge-due`(크론, `CRON_SECRET` 검증)
- **가입 API 개편** (`api/auth/signup.ts`): 포트원 인증 결과(imp_uid)를 서버에서 조회·검증해 CI 추출·저장, 중복 CI 거부
- **기능 접근 제어**: JWT에 구독 상태를 넣지 않고(해지·정지 즉시 반영 불가) 각 API가 DB에서 구독 상태 확인. `api/usage.ts`의 `increment_usage` 호출 직전이 게이트 위치 — 기존 사용량 제한과 같은 자리라 수정 범위 최소
- **크론 등록**: `vercel.json`에 `/api/billing?action=charge-due` 새벽 스케줄 추가 (기존 소싱 크론 `0 18 * * *`과 별도)
- **프론트 신규 화면**: 구독/결제 페이지 · 마이페이지(구독 상태·결제 이력·카드 변경·해지) · 관리자 쿠폰/구독 관리
- **일일 사용량 제한 40회 유지**: 쿠팡 수집·AI 호출은 건당 원가 발생 — "무제한" 대신 "충분한 한도"로 안내해 원가 방어

## 7. 법적 · 운영 필수사항

- **결제 예정 사전 고지** — 결제일 최소 7일 전 이메일/문자 고지 (여신전문금융업법 의무)
- **환불 정책 약관 명시** — "7일 이내 미사용 전액 환불, 이후 일할 환불(월요금÷30×잔여일)" 산식과 사용 이력 기준을 약관에 명시
- **미성년자** — 본인인증으로 만 14세 미만 가입 차단
- **빌링키 보안** — 카드번호는 서버에 절대 저장하지 않음(토스 보관), 빌링키도 암호화 저장
- **현금영수증 · 세금계산서** 발행 대응

## 8. 구현 로드맵

| 단계 | 내용 | 비고 |
|------|------|------|
| P0 | 토스 빌링 심사 접수 · 포트원 신청 · 약관 문서 | 개발과 병행, **지금 접수** (통신판매업·토스 가입은 완료) |
| P1 | DB 스키마 + `/api/billing.ts` 골격 | 토스 테스트 키로 빌링키 발급 → 결제 → 웹훅까지 |
| P2 | 가입 플로우 본인인증 | PASS 인증 + CI 중복 차단, 수동 승인 대체 |
| P3 | 구독 페이지 + 마이페이지 + 기능 접근 게이트 | 기존 회원에게 "구독 시작" 유도 |
| P4 | 쿠폰 시스템 | 검증·적용 + 관리자 쿠폰/구독 관리 |
| P5 | 자동결제 크론 | 결제일 청구 + 재시도(D+1/D+3) + 사전 고지·영수증 이메일 |
| P6 | 실키 전환 → 소프트 오픈 | 내부 실결제 검증 → **수강생 전원 무료 1개월 쿠폰 배포**로 소프트 오픈 → 일반 오픈 |

기존 수강생 데이터(관심 키워드, 순위 추적 이력 등)는 전부 유지되며, 오픈 시점 전원 무료 1개월 쿠폰으로 반발 없이 전환합니다.
